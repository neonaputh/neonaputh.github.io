About the website

Northline Financial is a static prototype for an independent financial advisor. It presents planning services, a sample client budget tracker, and illustrative analytics.

How it was built

Semantic HTML structures the pages, CSS provides their visual design and responsive layout, and JavaScript powers the mock create, read, update, and delete workflow. Chart.js is used for the analytics charts.

Important note

All displayed financial information is fictional sample data for this coursework. It is not investment advice, a performance promise, or a real financial advisor offer.
